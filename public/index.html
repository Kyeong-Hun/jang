모든 기록을 삭제할까요?

로그인한 계정의 배변·식사·생활 기록과 수정 이력을 삭제합니다.

삭제한 기록은 복구할 수 없습니다. Firebase 계정과 화면 설정은 유지되며, 이전에 직접 다운로드한 JSON 파일은 삭제되지 않습니다.

나의 프로필을 완성해 주세요

처음 이용할 때 한 번만 입력해요. 기존 사용자도 프로필을 설정할 수 있어요. 정보는 건강 기록과 함께 기기에서 암호화되어 저장됩니다.

프로필 개인정보 안내

이름·닉네임과 연령대는 프로필 표시 및 개인 기록 확인에 사용되는 필수 입력 항목입니다. 성별은 선택사항이며 입력하지 않아도 이용할 수 있어요.

프로필과 직접 작성한 건강기록은 기기에서 암호화한 후 계정에 저장됩니다. 계정 이용 중 보관되며 설정에서 프로필을 변경하고 기록을 삭제할 수 있어요.

Firebase 설정이 필요해요

아직 프로젝트 연결 정보가 입력되지 않았어. index.html 안의 firebaseConfig를 Firebase 콘솔의 웹 앱 설정값으로 바꿔줘.

설정 전에는 로그인과 기록 저장을 사용할 수 없어. 기존 데이터는 자동 전송되지 않아.

배변 기록을 내 계정에 안전하게 저장해요.

비밀번호: 8자 이상, 영문 소문자·숫자·특수기호를 각각 1개 이상 포함하세요. 대문자도 사용할 수 있어요.

개인정보 수집·이용 안내

가입 시: 이메일 주소와 비밀번호를 계정 생성·로그인·이메일 인증에 사용합니다. 인증 정보는 Firebase Authentication에서 처리합니다.

이용 중: 프로필의 이름·연령대와 직접 작성한 식사·배변·생활 기록은 앱 기능 제공 및 개인 기록 분석을 위해 저장됩니다. 성별·프로필 사진은 선택사항입니다.

보관·보호: 건강기록과 프로필은 기기에서 암호화한 후 계정별로 저장하며, 계정을 이용하는 동안 보관됩니다. 기록 삭제·문의는 앱의 설정 및 소통 센터에서 할 수 있습니다.

건강 관련 정보는 민감할 수 있어요. 입력 전에 안내를 확인해 주세요. 만 14세 미만 이용자의 개인정보 처리에는 법정대리인의 동의·확인 절차가 별도로 필요할 수 있습니다.

민감한 건강 기록이므로 다른 사람과 비밀번호를 공유하지 마세요. 기록은 기기에서 암호화해 저장합니다. 복구 키는 다른 사람에게 공유하지 마세요.

이메일 인증이 필요해요

가입한 이메일로 보낸 인증 링크를 누른 다음 아래 버튼을 눌러줘.

PRIVATE RECORDS

내 기록 잠금 해제

안전한 기록 암호화를 위해 로그인 비밀번호를 한 번 더 확인해요. 새 기기에서 로그인할 때는 방금 입력한 비밀번호를 자동으로 사용합니다.

ONE-TIME SECURITY SETUP

내 기록 보안 설정

기록을 사용자 기기에서 암호화하고, 서버에는 암호문만 저장합니다.

이 복구 키는 최초 1회만 표시합니다. 비밀번호를 잊거나 재설정한 뒤 이전 기록을 복구하려면 꼭 필요해요. 운영자도 대신 발급할 수 없습니다.

RECOVER ENCRYPTED RECORDS

내 기록 복구

이전에 발급받은 복구 키로 기존 기록의 암호화 열쇠를 되찾을 수 있어요. 새로운 로그인 비밀번호로 열쇠를 다시 보호합니다.
